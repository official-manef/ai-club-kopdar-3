# Panduan Interaktif Kopdar Tangsel 3

Handout praktik berbahasa Indonesia tentang perjalanan dari ide personal branding ke Threads. Judul halaman menyebut Kopdar Tangsel 3, sementara deskripsi di HTML menyebut GetHermes.cloud, Repliz.com, dan Threads serta merangkum materi sebagai tujuh langkah, flowchart, prompt siap salin, dan QR code.

## Membuka halaman

Buka `index.html` langsung di browser. Tidak diperlukan instalasi atau build untuk melihat halaman statis ini.

## Navigasi

Halaman dirancang sebagai panduan interaktif satu halaman. Gunakan navigasi dan kontrol yang tersedia di dalam halaman untuk menjelajahi materinya.

## Isi repositori

- `index.html` — halaman panduan, dengan gaya visual yang ditulis langsung di dalam berkas.

## Batasan dan verifikasi

Repositori yang tersedia berisi satu berkas HTML dan tidak mencantumkan langkah build atau perintah tes. Penyebutan layanan dalam materi tidak dengan sendirinya membuktikan adanya integrasi dengan layanan tersebut. Isi dan perilaku halaman belum dinyatakan telah diuji di browser.
